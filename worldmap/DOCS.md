# Worldmap

All your trips on one map. Open **Worldmap** in the sidebar.

1. **Connectors** – add the people to track (`person.*` / `device_tracker.*` entities with GPS),
   photo folders (below `/media` or `/share`) and notifications.
2. **Import** – drop Google Timeline exports, CSV/Excel, GPX or KML files. A preview shows what was found.
3. **Questions** – answer "who was there?" for new trips.
4. **+ Trip by hand** – add old trips without any data; they appear as an estimated area on the map.

Privacy: all data stays in this add-on (`/data`, included in backups). Only when routing is set to
`osrm` are the start and end point of a gap sent to the routing server.

Full documentation (English and German): https://github.com/magi1982/worldmap
